# Gainesville Georgia Churches Database

## Project Overview
Comprehensive database of 130 churches in Gainesville, Georgia area with verified contact information.

## Data Sources
- FaithStreet Directory (130+ churches)
- SBC Churches Directory (Baptist churches)
- North Georgia Conference UMC (Methodist churches)
- ChurchFinder.com
- Yelp and Yellow Pages (verified phone numbers and addresses)
- Gainesville Times Churches Directory

## Church Breakdown by Denomination
- Baptist (SBC): 47 churches
- Methodist (UMC): 14 churches  
- Non-Denominational: 11 churches
- Church of God (Cleveland, TN): 3 churches
- Church of God of Prophecy: 2 churches
- Assemblies of God: 4 churches
- Other Denominations: ~49 churches

**Total Target: 130 churches**

## CSV Files Included
1. `gainesville-baptist-churches.csv` - All Baptist churches with verified contact info
2. `gainesville-methodist-churches.csv` - All Methodist/UMC churches
3. `gainesville-other-denominations.csv` - All other denominations
4. `gainesville-churches-complete.csv` - Master file with all 130 churches
