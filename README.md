# Church Compass

A web application to help people find the right church for them.

## Getting Started

### Prerequisites
- Node.js 16+ and npm

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Building

```bash
npm run build
npm start
```

## Project Structure

- `/app` - Next.js app directory with pages and layouts
- `/public` - Static assets
- `/components` - Reusable React components (to be created)

## Technologies

- **Next.js** - React framework for production
- **React** - UI library
- **TypeScript** - Type safety
- **CSS** - Styling
